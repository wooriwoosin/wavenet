# 유통사업부 유통마진 대시보드

상부정산·전체정산 원본 파일(.xls)을 올려 상품별 마진을 계산하고, **월별로 구글 시트에 저장**해서
월별 대시보드·추이 분석·**발표 모드**로 볼 수 있는 단일 HTML 앱입니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 웹앱 (GitHub Pages로 배포) |
| `apps-script/Code.gs` | 구글 시트 저장/조회 API (Google Apps Script) |

## 화면 구성

- **정산 입력** — 정산 월 선택 → 상부정산/전체정산 파일 업로드 → 계산 → `구글 시트에 저장` (같은 월은 덮어쓰기, 작성한 사유는 유지)
- **월별 대시보드** — 유통 고객수 · 총 유통마진 · 고객당 마진 · 역마진 고객 (전월 대비), 협력점별 유통마진 표·차트
  - `고객당 마진` / `역마진 고객` 카드 또는 협력점 행 클릭 → **저마진 고객 점검 창** (1만원 미만 / 역마진 / 사유 미작성, 협력점별 필터, 사유 메모 입력)
- **추이 분석** — 월별 유통마진, 고객수(외부/자점), 고객당 마진, 협력점 × 월 표
- **▶ 발표 모드** — 표지 → 핵심 지표 → 협력점별 표·차트 → 저마진·역마진 점검 → 월별 추이
  - `→` / `Space` / 화면 오른쪽 클릭: 다음, `←` / 화면 왼쪽 클릭: 이전, `Esc`: 종료

## 1. 구글 시트 연동 설정 (최초 1회)

1. 구글 시트(`1rFwSqrdn_QTIm_Nz6g386mrRREa-q4jMHnGlQ1uP03o`)를 엽니다.
2. **확장 프로그램 → Apps Script** 를 열고, 기본 `Code.gs` 내용을 지운 뒤 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. 편집기 상단에서 함수 `setup` 을 선택하고 **실행** → 권한 승인. 시트에 `정산데이터`, `월별요약` 탭이 생깁니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/.../exec` URL을 복사합니다.
5. 웹앱 URL은 `index.html` 의 `DEFAULT_API_URL` 에 설정되어 있습니다. (다른 URL은 로그인 화면의 `연결 설정`에서 변경)

> `Code.gs` 를 수정한 경우 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영됩니다.

URL을 설정하지 않으면 **로컬 모드**로 동작하며 데이터는 현재 브라우저에만 저장됩니다.

## 로그인 / 계정

- 모든 데이터 조회·저장은 로그인해야 가능합니다 (서버(Apps Script)에서 검증, 로그인 유지 6시간 / 브라우저 탭 닫으면 로그아웃).
- 초기 계정: 아이디 `admin` — **첫 로그인 후 상단 `비밀번호 변경`으로 반드시 변경하세요.**
- 비밀번호는 원문이 아닌 salt + SHA-256 해시로 스크립트 속성 `USERS` 에 저장됩니다.
- 10분 내 5회 로그인 실패 시 해당 아이디는 10분간 잠깁니다.
- 계정 추가 / 비밀번호 분실 시: Apps Script 편집기에서 `addUser` 함수의 아이디·비밀번호를 바꿔 실행하세요.

### 시트 구조

- `유통_월별요약` — 월별 고객수·상부정산·자점마진·전체정산·유통마진·고객당마진·1만원미만·역마진
- `유통_협력점별` — 월 × 협력점 집계 (자점 여부 포함)
- `유통_저마진고객` — 유통마진 1만원 미만(역마진 포함) 고객 목록 + 사유 메모. 연락처는 뒷 4자리만 저장

## 계산 기준 (유통마진)

- **대상: 순수 이관건** — 상부점이 `숫자.`로 시작하는 자체 코드건은 제외 (예: `1.유KT-우리(도매)`, `5.유KT-대성_…`). 그 외 상부점(광합성, 시온정보통신, 소망텔레콤무선 등)은 모두 이관건
- 정산종류 `일반`, 개통상태 `개통완료`만. 상품명에 `정산관련`·`추가지급`이 들어간 행 제외. 유선기타는 `인터넷` 상품만 (인터넷전화 제외). 모바일은 가입서비스가 `(기기)`인 건 제외 (`(유심)`만)
- **금액 = 약정금액 + 번들수수료 + 동판수수료** (차감내역 사은품·물류·쿠폰·선납·할인탭·미비서류·기타, 수납은 미반영) — 상부정산·전체정산 동일
- **자점** (0.영업정산, 1.시흥영업팀, 2.천안영업팀, 3.부천영업팀(미사용), 4.우신기술사업부, 5.상권사업부, 6.우성영업사업부, 7.유통사업부, 8.우신영업사업부, 9.모바일유통사업부)과 자점 상담 협력점(**와이즐리·크레소티**)은 제외하지 않고 **자점마진반영**:
  인터넷 1건당 10만원, 모바일 1건당 10만원, SKYLIFE 모바일 5만원 차감 (TV·부가상품·렌탈은 차감 없음)
- **유통마진 = 상부정산 − 자점마진 − 전체정산**
- **고객 = 고객명 + 연락처** (주민번호 열이 원본에 없음). 유통건수 = 고객수
- 저마진 = 고객당 유통마진 1만원 미만, 역마진 = 0원 미만
- 상부정산 행과 전체정산 행은 고객명·연락처·상품명·상품옵션·접수일·최초등록일로 1:1 매칭
