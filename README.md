# 유통사업부 도매 정산 대시보드

상부정산·전체정산 원본 파일(.xls)을 올려 상품별 마진을 계산하고, **월별로 구글 시트에 저장**해서
월별 대시보드·추이 분석·**발표 모드**로 볼 수 있는 단일 HTML 앱입니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 웹앱 (GitHub Pages로 배포) |
| `apps-script/Code.gs` | 구글 시트 저장/조회 API (Google Apps Script) |

## 화면 구성

- **정산 입력** — 정산 월 선택 → 상부정산/전체정산 파일 업로드 → 계산 → `구글 시트에 저장` (같은 월은 덮어쓰기)
- **월별 대시보드** — 저장된 월을 골라 KPI(전월 대비 증감), 핵심 포인트, 상품별 표, 차트 확인 / 엑셀 다운로드 / 월 삭제
- **추이 분석** — 최근 6·12개월·전체 기간의 상부정산·전체정산·마진 추이, 건수, 건당 마진, 상품×월 표
- **▶ 발표 모드** — 선택한 월 기준 16:9 슬라이드 (표지 → 종합 요약 → 핵심 포인트 → 상품별 표 → 차트 → 월별 추이)
  - `→` / `Space` / 화면 오른쪽 클릭: 다음, `←` / 화면 왼쪽 클릭: 이전, `Esc`: 종료

## 1. 구글 시트 연동 설정 (최초 1회)

1. 구글 시트(`1rFwSqrdn_QTIm_Nz6g386mrRREa-q4jMHnGlQ1uP03o`)를 엽니다.
2. **확장 프로그램 → Apps Script** 를 열고, 기본 `Code.gs` 내용을 지운 뒤 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. (권장) **프로젝트 설정(⚙) → 스크립트 속성**에 `API_KEY` = 임의의 비밀 문자열 을 추가합니다.
   설정하면 이 키를 아는 사람만 읽기/쓰기가 가능합니다.
4. 편집기 상단에서 함수 `setup` 을 선택하고 **실행** → 권한 승인. 시트에 `정산데이터`, `월별요약` 탭이 생깁니다.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/.../exec` URL을 복사합니다.
6. 웹앱 우측 상단 **⚙ 설정**에 URL(과 API 키)을 입력 → `연결 테스트` → `저장`.
   - 팀 전체가 같은 URL을 쓰려면 `index.html` 의 `DEFAULT_API_URL` 에 URL을 넣고 커밋해도 됩니다.
     (API 키는 커밋하지 말고 각자 설정 창에 입력하세요.)

> `Code.gs` 를 수정한 경우 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영됩니다.

URL을 설정하지 않으면 **로컬 모드**로 동작하며 데이터는 현재 브라우저에만 저장됩니다.

### 시트 구조

- `정산데이터` — 월 · 상품 · 건수 · 상부정산 · 전체정산 · 마진 · 저장일시 · 메모 (앱이 읽고 쓰는 원본)
- `월별요약` — 월별 합계·건당마진·마진율 (저장/삭제 때마다 자동 재생성, 사람이 보기 위한 용도)

## 2. GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
브랜치(예: `main`)와 `/ (root)` 를 선택하면 `https://wooriwoosin.github.io/wavenet/` 에서 열립니다.

> Pages 주소는 누구나 열 수 있으므로, 정산 데이터 보호를 위해 위의 `API_KEY` 설정을 권장합니다.
> (HTML 자체에는 정산 데이터가 들어있지 않고, 데이터는 API 키가 있어야 구글 시트에서 불러옵니다.)

## 계산 기준

기존 도매정산 앱(v2)의 필터·상품 분류·계산 로직을 그대로 사용합니다.

- 공통 필터: 제외 협력점/상부점, `정산종류 = 일반`, `개통상태 = 개통완료`, 상품명 제외 키워드(정산관련·추가지급·전화)
- 상부정산(A) = `정산금액` 합계
- 전체정산(B) = SKB·HV 유선은 `약정금액`, 그 외는 `약정+번들+동판 − (물류·쿠폰·선납·할인탭·미비서류·기타 차감 + 수납)`
- 마진 = A − B
